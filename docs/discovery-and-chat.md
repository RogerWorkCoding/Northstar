# Discovery and Chat are different experiences

**Product principle (Roger, Oct 19, 2026).** Read before any UX, navigation, routing, connector or
Discovery change.

## The rule

- Chat is NOT the default next screen after Discovery. Discovery is NOT a shortcut to Chat.
- **Discovery** helps people explore, evaluate, compare and choose paths forward. It stays visual,
  guided and action-oriented, and tries to solve the problem without a conversation.
- **Chat** is for when conversation creates more value than visual exploration: long explanations,
  complex reasoning, emotional situations, reflection, brainstorming, detailed planning, architecture
  discussions, connector-assisted personal guidance, lots of back-and-forth.
- Chat is entered **intentionally**. Discovery may offer **"Discuss in Chat"** when the content gets
  long, several clarifying questions are needed, connected personal data would help a lot, or the
  person asks to talk.

## Discovery experience

- Keep the person in context. Reveal information progressively:
  recommendations → details → actions.
- Avoid unnecessary screen transitions. Feel like one evolving experience, not separate pages.

```
Prefer:   Problem → Discovery → more Discovery → more Discovery
Avoid:    Problem → Discovery → Chat → Results → Reviews
```

Example, "Toothache": find nearby dentists, compare providers, why each was picked, reviews,
ratings, distance, appointment options. All inside Discovery where practical.

## Connectors

Connectors improve Discovery and Chat; they are not a way to move someone into Chat.
Example: Discovery "Plan my week" → "Connect Calendar and I can help find time." After connecting,
the person stays in Discovery.

## Discovery home

Simple: ⭐ Northstar · "What's on your mind?" The person gives a goal, challenge, problem or question;
Northstar chooses the path.

## Check every new feature

1. Can this remain inside Discovery?
2. Does Chat genuinely add value?
3. Is this creating an unnecessary screen transition?
4. Is Northstar helping the person move forward, or just moving them between screens?

Safety exception: someone in crisis goes straight to Northstar's crisis help (Chat), always.
